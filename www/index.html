Security Policies &amp; Rules

User Responsibilities

  • Master Key Custody: You are solely responsible for memorizing and safeguarding your Master Password and 12-word Recovery Mnemonic.
  • Zero-Knowledge Limitation: If credentials are lost, VNS cannot recover, reset, or access your vault under any circumstances.
  • Device Security: You must ensure the physical security of the device where local sandbox partitions are mounted.

VNS Group Commitments

  • Absolute Privacy: All encryption and decryption processes execute entirely offline on your local device CPU.
  • No Telemetry: The application does not collect, track, or broadcast your personal data, passwords, or usage metrics.
  • Military-Grade Cipher: Data is secured using AES-GCM-256 bit encryption and PBKDF2 key derivation algorithms.

Backup &amp; Local Sync Architecture

  • Encrypted Storage Payloads: All exported backup files (.JSON or String) remain fully encrypted with your 12-word seed key prior to file generation.
  • Air-Gapped Tether Sync: Data transfers between mobile terminals and desktop nodes occur via direct USB / local sockets without intermediary servers.

Payment Card Isolated Matrix
